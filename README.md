# Facets

A growing toolbox for builders using [FastAsyncWorldEdit](https://github.com/IntellectualSites/FastAsyncWorldEdit) on Paper.

📖 **Documentation: [the wiki](https://github.com/Darkvodou/Facets/wiki)**

## Features

- **Selections**: [Loft](https://github.com/Darkvodou/Facets/wiki/Loft)
- **Masks**: [`#panes`](https://github.com/Darkvodou/Facets/wiki/Panes-Mask), [`#glass`](https://github.com/Darkvodou/Facets/wiki/Glass-Mask), [`#fhotbar`](https://github.com/Darkvodou/Facets/wiki/Hotbar-Mask), [`#faim`](https://github.com/Darkvodou/Facets/wiki/Aim-Mask), [`#gcurrent`](https://github.com/Darkvodou/Facets/wiki/Current-Mask), [`#noocclusion`](https://github.com/Darkvodou/Facets/wiki/Occlusion-Masks)
- **Patterns**: [`#panes`](https://github.com/Darkvodou/Facets/wiki/Panes-Mask), [`#glass`](https://github.com/Darkvodou/Facets/wiki/Glass-Mask), [`#fhotbar`](https://github.com/Darkvodou/Facets/wiki/Hotbar-Mask), [`#faim`](https://github.com/Darkvodou/Facets/wiki/Aim-Mask)
- **Tools**: [Fuzzy fill](https://github.com/Darkvodou/Facets/wiki/Fuzzy-Fill), [Symmetry](https://github.com/Darkvodou/Facets/wiki/Symmetry), [Gravity](https://github.com/Darkvodou/Facets/wiki/Gravity), [Fix cover](https://github.com/Darkvodou/Facets/wiki/Fix-Cover), [Deform magnet](https://github.com/Darkvodou/Facets/wiki/Deform-Magnet), [Speed](https://github.com/Darkvodou/Facets/wiki/Speed), [Replace color](https://github.com/Darkvodou/Facets/wiki/Replace-Color), [Type replace](https://github.com/Darkvodou/Facets/wiki/Type-Replace), [Variants](https://github.com/Darkvodou/Facets/wiki/Variants), [Menu](https://github.com/Darkvodou/Facets/wiki/Menu)
- **Brushes**: [Magnet](https://github.com/Darkvodou/Facets/wiki/Magnet-Brush)

Permissions and configuration: [Installation](https://github.com/Darkvodou/Facets/wiki/Installation), [Configuration](https://github.com/Darkvodou/Facets/wiki/Configuration).

## Requirements
- Paper 1.21+
- FastAsyncWorldEdit 2.16+
- Java 21

## Building
```bash
./gradlew build
```
The plugin jar is written to `build/libs/`.

## Versions
Versions follow [Semantic Versioning](https://semver.org): see [Versions](https://github.com/Darkvodou/Facets/wiki/Installation#versions).
